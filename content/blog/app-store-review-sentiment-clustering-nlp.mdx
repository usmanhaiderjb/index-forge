## The 4 Steps of Automated Review Intelligence

### Step 1: Normalization & Multi-Language Translation
App reviews arrive in dozens of languages: German, Japanese, Portuguese, Arabic, and English.
1. The NLP pipeline detects the source language.
2. It translates non-English text to standardized English tokens while preserving the original sentiment score.
3. It strips boilerplate noise (e.g. *"This app is"*, *"I think that"*, emojis).

### Step 2: N-Gram Extraction & Lemmatization
The engine tokenizes sentences into **Unigrams (single words)** and **Bigrams/Trigrams (multi-word phrases)**, applying lemmatization to merge morphological variations:

```
"keeps crashing on startup"  --> [crash, startup]
"crashed when I opened it"   --> [crash, open]
"crashes every time on open" --> [crash, open]

--> Clustered into single entity: "startup_crash" (Frequency: 3,412 mentions)
```

### Step 3: Sentiment Intensity Scoring
Each review receives a compound sentiment score between `-1.0` (Severe Anger/Frustration) and `+1.0` (Delight/Advocacy), weighted by star rating:

| Review Excerpt | Extracted Entities | Sentiment Score | Category Assignment |
| :--- | :--- | :--- | :--- |
| *"Love the UI but crashes every time I export PDF!"* | `[ui_design, pdf_export, crash]` | **-0.45 (Mixed)** | **Technical Bug** |
| *"Charged my card $49.99 without asking! Scam!"* | `[unauthorized_charge, billing]` | **-0.95 (Critical)** | **Monetization UX** |
| *"Best widget on iOS 18. Super clean daily streaks."* | `[widget, streaks, design]` | **+0.88 (Delight)** | **Feature Advocacy** |

### Step 4: Root Cause Theme Clustering
The algorithm groups co-occurring entities into **Root Cause Themes** using Latent Dirichlet Allocation (LDA) or semantic embedding vectors.

## Translating Review Themes into Rating Recovery

When you identify a negative review cluster, calculate the **Star Rating Impact `(Delta Stars)`**:

```
Star Rating Impact = (Cluster Volume / Total Reviews) x (5.0 - Cluster Avg Rating)
```

If a single bug (e.g. an iCloud sync failure on iOS 18) generates 1,200 1-star reviews in a pool of 10,000 total reviews, fixing that single bug will raise your incoming rolling rating from **3.9 stars to 4.4 stars**:

```math
\Delta \text{Stars} = \left(\frac{1{,}200}{10{,}000}\right) \times (5.0 - 1.0) = 0.12 \times 4.0 = +\mathbf{0.48\text{ Stars}}
```
